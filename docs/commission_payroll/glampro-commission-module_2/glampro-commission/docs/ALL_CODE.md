````md
## 1. What this module does (business summary)

Eurosense (a Glampro salon) pays staff commission on:

| Commission type (code) | When it is earned | Base amount | Who earns it |
|---|---|---|---|
| `SVC` cash service | service paid normally | net line amount (after discount, excl. GST) | Performed by |
| `PRD` product | product sold | net line amount (category kept, e.g. "Beauty") | Sold by |
| `PKG_SALE` package sale | **each payment collected** (deposit / instalment / full) | **cash collected** – negative on refund | Sold by (split) |
| `PKG_RED` on course / redemption | each session used | holding's **session value** = net price ÷ sessions (snapshot) | Performed by (split) |
| `FOC` complimentary service | FOC service done | service list price (the plan applies base %, e.g. 50%) | Performed by |
| `VP_SALE` / `VP_SPEND` value package | sold / credit spent | cash paid / credit × paid ÷ credit | Sold by / Performed by |

Every staff member is on a **commission plan** (e.g. *Hair Commission Scheme 2022*, *TP Mani & Pedi Scheme*).
A plan has **components** (e.g. "Cash Service & Package", "On course", "Product", "FOC"), **stages** by tenure
(e.g. *New staff* months 1–3) and **incentives** (group + individual target, personal target).

A component pools the month's base of its commission types and applies one **method**:

| Method | Rule | Example: bands 0–7,000 @5%, 7,000–15,000 @7%; base 8,985.50 |
|---|---|---|
| `FLAT` | base × rate | – |
| `TIER_WHOLE` | rate of the band reached × **whole** base ("retroactive") | 8,985.50 × 7% = **628.99** |
| `TIER_SLICE` | each band's rate on its own slice ("progressive") | 7,000 × 5% + 1,985.50 × 7% = **488.99** |
| `TIER_MIXED` | per band: `WHOLE` (from $1) or `SLICE` | depends on band settings |
| `FIXED_PER_UNIT` | fixed S$ × number of items | – |

Rates are decided at **month end** (because tiers depend on the monthly total). During the month the POS only writes
**base lines** (no rates) to the **Commission Base Ledger**.

Owner decisions (do not change without the owner): **D-1** package sale base = cash collected · **D-5** the plan
and plan version in force on the **last day of the month** apply to the whole month · **D-7** refund takes back only
the sale commission on the refunded part, redemption commission stays · **D-8** only paid-for sessions can be
redeemed (manager PIN override allowed and logged).

## 3. Golden rules (the AI must follow these)

1. **Money is never a JS `number`.** Use `Decimal` via `D()` from `shared/src/money.ts`. API/DB values are strings
   like `"1234.50"`. Rates are strings like `"7"` (= 7 %). Round with `money2()` (2 dp, half-up) only for final
   amounts; ledger base lines use `money4()`.
2. **The engine stays pure.** Nothing in `shared/` may import Node, Express, Prisma or React.
3. **The ledger is append-only.** Never update `baseAmount`. To correct: mark `REVERSED` (open period) or post a
   negative line in the next open period (approved period) – see `LedgerService.reverseLines()`.
4. **Approved periods are locked.** Any change that touches a locked month posts to the next open month.
5. **Snapshots.** Session value is fixed at purchase; period results store plan version, stage and band reached.
   Publishing a new plan version never changes past months.
6. **Effective dating.** Plan versions have `effectiveFrom`; assignments have `fromDate/toDate`.
7. **Every manual change needs a reason** and writes `repo.audit(...)`.
8. **Permissions** (SRS §4.11): only `SUPER_ADMIN` creates/publishes plans, approves periods, edits salaries;
   `MANAGER` can refund, void, correct staff, override, adjust; `STAFF` sees only their own data.
9. **Keep the `CommissionRepo` interface and `CommissionApi` interface in sync** when adding features
   (MemoryRepo + PrismaRepo, HttpApi + DemoApi).
10. **Add/adjust tests** in `shared/tests` (engine) or `backend/tests` (API) for every change; run `npm test`.
````

```ts
/**
 * Impact preview (FR-SET-10): re-run a closed month with published rules vs a draft.
 */
import { BaseLine, PlanDefinition } from '../types.js';
import { D, ZERO, money2 } from '../money.js';
import { calculateStaffPeriod } from './period.js';

export interface ImpactStaffInput {
  staffId: string;
  staffName: string;
  joinDate: string | null;
  stageEndOverride?: number | null;
  lines: BaseLine[];
  carryForward?: Record<string, string>;
}

export function impactPreview(periodKey: string, published: PlanDefinition, draft: PlanDefinition, staff: ImpactStaffInput[], groupMetric: string | null) {
  const rows = staff.map((s) => {
    const base = { staffId: s.staffId, periodKey, joinDate: s.joinDate, planId: null, planVersionId: null, stageEndOverride: s.stageEndOverride, lines: s.lines, carryForward: s.carryForward, groupMetric };
    const a = calculateStaffPeriod({ ...base, definition: published });
    const b = calculateStaffPeriod({ ...base, definition: draft });
    const pub = D(a.commissionTotal).plus(D(a.incentiveTotal));
    const drf = D(b.commissionTotal).plus(D(b.incentiveTotal));
    return { staffId: s.staffId, staffName: s.staffName, stage: b.stageName, published: money2(pub), draft: money2(drf), change: money2(drf.minus(pub)) };
  });
  const tp = rows.reduce((s, r) => s.plus(D(r.published)), ZERO);
  const td = rows.reduce((s, r) => s.plus(D(r.draft)), ZERO);
  return { periodKey, rows, totalPublished: money2(tp), totalDraft: money2(td), totalChange: money2(td.minus(tp)) };
}
```

## shared/src/engine/incentive.ts

```ts
/**
 * Incentives (FR-INC). Pays the amount of the HIGHEST row whose conditions are all met.
 * Rows are not cumulative.
 */
import { IncentiveResult, IncentiveRule } from '../types.js';
import { D, money2 } from '../money.js';

export function evaluateIncentive(rule: IncentiveRule, individualMetric: string, groupMetric: string | null): IncentiveResult {
  let best: number | null = null;
  rule.rows.forEach((row, i) => {
    const indOk = D(individualMetric).gte(D(row.individualTarget));
    const grpOk = rule.type === 'INDIVIDUAL_TARGET' || (groupMetric !== null && D(groupMetric).gte(D(row.groupTarget ?? '0')));
    if (indOk && grpOk && (best === null || D(row.amount).gt(D(rule.rows[best].amount)))) best = i;
  });
  return {
    ruleKey: rule.key,
    name: rule.name,
    individualMetric: money2(individualMetric),
    groupMetric: rule.type === 'GROUP_AND_INDIVIDUAL' && groupMetric !== null ? money2(groupMetric) : null,
    rowIndex: best,
    amount: best === null ? '0.00' : money2(rule.rows[best].amount),
  };
}
```

## shared/src/engine/package.ts

```ts
/**
 * Package maths shared by POS (frontend) and ledger services (backend).
 *  - session value snapshot (FR-POS-06)
 *  - D-8: only paid-for sessions can be redeemed (FR-POS-08)
 *  - D-7: refund amount; only sale commission on the refunded part is taken back (FR-ADJ-01/02)
 */
import { D, Decimal, ZERO, money2, money4 } from '../money.js';

/** session value = net package price (after discount, excl. GST) ÷ sessions, 4 dp */
export function sessionValue(netPrice: string, sessions: number): string {
  if (sessions <= 0) throw new Error('Package must have at least 1 session');
  return money4(D(netPrice).div(sessions));
}

/** D-8: sessions the customer has paid for = floor(cash collected ÷ session value), capped at total. */
export function paidSessions(cashCollected: string, sessionVal: string, totalSessions: number): number {
  if (D(sessionVal).lte(0)) return totalSessions;
  // small epsilon so 2,000.00 / 1,000.0000 is exactly 2 even with rounding of session value
  const n = D(cashCollected).plus('0.005').div(D(sessionVal)).floor().toNumber();
  return Math.max(0, Math.min(totalSessions, n));
}

export function canRedeem(h: { cashCollected: string; sessionValue: string; sessionsTotal: number; sessionsUsed: number }): { ok: boolean; paid: number; reason?: string } {
  const paid = paidSessions(h.cashCollected, h.sessionValue, h.sessionsTotal);
  if (h.sessionsUsed >= h.sessionsTotal) return { ok: false, paid, reason: 'No sessions left on this package.' };
  if (h.sessionsUsed >= paid) return { ok: false, paid, reason: `Only ${paid} of ${h.sessionsTotal} sessions are paid for. Collect the balance first (or manager PIN override).` };
  return { ok: true, paid };
}

/** minimum deposit check (FR-POS-04) */
export function minDeposit(netPrice: string, minDepositPct: string): string {
  return money2(D(netPrice).mul(D(minDepositPct)).div(100));
}

/** D-7 refund = cash collected − sessions used × session value − admin fee (never below 0). */
export function refundAmount(cashCollected: string, sessionsUsed: number, sessionVal: string, adminFee: string): string {
  const r: Decimal = D(cashCollected).minus(D(sessionVal).mul(sessionsUsed)).minus(D(adminFee));
  return money2(r.lt(0) ? ZERO : r);
}

/** Value package spend base (FR-BAS-07): credit spent × paid ÷ credit. */
export function valuePackageSpendBase(creditSpent: string, paid: string, credit: string): string {
  if (D(credit).lte(0)) return '0.0000';
  return money4(D(creditSpent).mul(D(paid)).div(D(credit)));
}
```

```ts
  lines: BaseLine[];
  /** Negative bases carried from last month, keyed by component key. */
  carryForward?: Record<string, string>;
  /** Group metric for GROUP_AND_INDIVIDUAL incentives (e.g. salon total cash collected). */
  groupMetric?: string | null;
  tenureOptions?: TenureOptions;
}

export function lineMatches(comp: PlanComponent, l: BaseLine): boolean {
  if (l.fixedCommission !== undefined && l.fixedCommission !== null) return false; // paid separately (FR-CAL-08)
  if (!comp.commissionTypes.includes(l.commissionType)) return false;
  const cat = l.productCategory ?? '';
  if (comp.categoryInclude?.length && !comp.categoryInclude.includes(cat)) return false;
  if (comp.categoryExclude?.length && comp.categoryExclude.includes(cat)) return false;
  return true;
}

export function sumLines(lines: BaseLine[], pred: (l: BaseLine) => boolean) {
  let base = ZERO;
  let units = 0;
  for (const l of lines) {
    if (l.status === 'REVERSED') continue;
    if (!pred(l)) continue;
    base = base.plus(D(l.baseAmount));
    units += l.units ?? 0;
  }
  return { base, units };
}

export function calculateStaffPeriod(input: StaffPeriodInput): StaffPeriodResult {
  const def = input.definition;
  const month = input.joinDate ? tenureMonth(input.joinDate, input.periodKey, input.tenureOptions) : null;
  const stage = resolveStage(def?.stages ?? [], month, input.stageEndOverride);
  const components = (def?.components ?? [])
    .slice()
    .sort((a, b) => a.sort - b.sort)
    .map((comp) => {
      const { base, units } = sumLines(input.lines, (l) => lineMatches(comp, l));
      return calcComponent(comp, base, { stageKey: stage.key, units, carryForwardIn: input.carryForward?.[comp.key] });
    });

  // Package-level fixed commissions bypass the plan (FR-CAL-08)
  let fixed = ZERO;
  let fixedUnits = 0;
  for (const l of input.lines) {
    if (l.status === 'REVERSED' || l.fixedCommission === undefined || l.fixedCommission === null) continue;
    fixed = fixed.plus(D(l.fixedCommission));
    fixedUnits += l.units ?? 0;
  }
  if (!fixed.isZero()) {
    components.push({
      componentKey: 'pkg_fixed', componentName: 'Package fixed commission', method: 'FIXED_PER_UNIT', rawBase: '0.0000', pooledBase: '0.0000',
      units: fixedUnits, bandIndex: null, bandLabel: 'fixed', ratePct: null, amount: money2(fixed), capped: false, nextThreshold: null,
      gapToNext: null, carryForwardOut: '0.0000', working: [{ from: '', to: '', amount: String(fixedUnits), ratePct: '', commission: money2(fixed), kind: 'FIXED', text: `${fixedUnits} item(s) with package fixed commission = ${money2(fixed)}` }],
    });
  }

  const incentives = (def?.incentives ?? []).map((rule) => {
    const { base } = sumLines(input.lines, (l) => rule.individualMetricTypes.includes(l.commissionType));
    return evaluateIncentive(rule, base.toString(), input.groupMetric ?? null);
  });

  const commissionTotal = components.reduce((s, c) => s.plus(D(c.amount)), ZERO);
  const incentiveTotal = incentives.reduce((s, c) => s.plus(D(c.amount)), ZERO);
  return {
    staffId: input.staffId,
    periodKey: input.periodKey,
    planId: input.planId,
    planVersionId: input.planVersionId,
    tenureMonth: month,
    stageKey: stage.key,
    stageName: stage.name,
    components,
    incentives,
    commissionTotal: money2(commissionTotal),
    incentiveTotal: money2(incentiveTotal),
  };
}

/** Flat-rule fallback for staff with no plan (FR-ASN-05 / FR-CAL-09). rates: type -> pct */
export function calculateFlatFallback(staffId: string, periodKey: string, lines: BaseLine[], rates: Partial<Record<string, string>>): StaffPeriodResult {
  const comp: PlanComponent = { key: 'flat_rules', name: 'Flat rules', commissionTypes: [], basePct: '100', method: 'FLAT', bands: [], sort: 0 };
  let amt = ZERO;
  let base = ZERO;
  for (const l of lines) {
    if (l.status === 'REVERSED') continue;
    const r = rates[l.commissionType];
    if (!r) continue;
    base = base.plus(D(l.baseAmount));
    amt = amt.plus(D(l.baseAmount).mul(D(r)).div(100));
  }
  return {
    staffId, periodKey, planId: null, planVersionId: null, tenureMonth: null, stageKey: 'std', stageName: 'Standard',
    components: [{ componentKey: comp.key, componentName: comp.name, method: 'FLAT', rawBase: base.toFixed(4), pooledBase: base.toFixed(4), units: 0, bandIndex: null, bandLabel: 'flat rules', ratePct: null, amount: money2(amt.isNeg() ? 0 : amt), capped: false, nextThreshold: null, gapToNext: null, carryForwardOut: '0.0000', working: [] }],
    incentives: [], commissionTotal: money2(amt.isNeg() ? 0 : amt), incentiveTotal: '0.00',
  };
}
```

```ts
/**
 * Tenure stages (FR-STG). Tenure month for period P = (yearP - yearJoin) * 12 + monthP - monthJoin + 1.
 * The join month is month 1. Optional rule: joined after day N => month 1 starts next month.
 */
import { PlanStage } from '../types.js';

export interface TenureOptions {
  /** If set, staff who join AFTER this day of month start counting from the following month (FR-STG-05). */
  joinAfterDayCountsNextMonth?: number | null;
}

/** periodKey "2026-09"; joinDate "2026-09-10" */
export function tenureMonth(joinDate: string, periodKey: string, opts: TenureOptions = {}): number {
  const [jy, jm, jd] = joinDate.split('-').map(Number);
  const [py, pm] = periodKey.split('-').map(Number);
  let m = (py - jy) * 12 + (pm - jm) + 1;
  if (opts.joinAfterDayCountsNextMonth && jd > opts.joinAfterDayCountsNextMonth) m -= 1;
  return m;
}

export const STANDARD_STAGE: PlanStage = { key: 'std', name: 'Standard', fromMonth: 1, toMonth: null };

/**
 * Stage whose month range contains the tenure month. `stageEndOverride` lets an admin extend /
 * shorten the FIRST stage for one staff member (FR-STG-04): the first stage then ends at that month.
 */
export function resolveStage(stages: PlanStage[], month: number | null, stageEndOverride?: number | null): PlanStage {
  if (!stages.length || month === null) return STANDARD_STAGE;
  const sorted = [...stages].sort((a, b) => a.fromMonth - b.fromMonth);
  if (stageEndOverride && sorted.length > 1) {
    if (month <= stageEndOverride) return sorted[0];
    return sorted.find((s, i) => i > 0 && (s.toMonth === null || month <= s.toMonth)) ?? sorted[sorted.length - 1];
  }
  const hit = sorted.find((s) => month >= s.fromMonth && (s.toMonth === null || month <= s.toMonth));
  if (hit) return hit;
  return month < sorted[0].fromMonth ? sorted[0] : sorted[sorted.length - 1];
}

/** Human schedule for the staff screen, e.g. [{stage, from:"2026-09", to:"2026-11"}, ...] */
export function stageSchedule(stages: PlanStage[], joinDate: string, opts: TenureOptions = {}) {
  const [jy, jm, jd] = joinDate.split('-').map(Number);
  let startIdx = jy * 12 + (jm - 1);
  if (opts.joinAfterDayCountsNextMonth && jd > opts.joinAfterDayCountsNextMonth) startIdx += 1;
  const key = (idx: number) => `${Math.floor(idx / 12)}-${String((idx % 12) + 1).padStart(2, '0')}`;
  return [...stages]
    .sort((a, b) => a.fromMonth - b.fromMonth)
    .map((s) => ({ stage: s, from: key(startIdx + s.fromMonth - 1), to: s.toMonth === null ? null : key(startIdx + s.toMonth - 1) }));
}
```

## shared/src/engine/tier.ts

```ts
/**
 * Component calculator – turns ONE component's pooled monthly base into commission.
 * Pure function: no database, no dates. Used by the month-end engine, the settings
 * test calculator, the impact preview and the POS month-to-date estimate (FR-CAL-04, FR-SET-07).
 *
 * Band semantics: band i covers base > upper(i-1) and <= upper(i). upper = null => no cap.
 *
 *  TIER_WHOLE : amount = rate(k) × base                               (k = band containing base)
 *  TIER_SLICE : amount = Σ_{i<=k} slice(i) × rate(i)
 *  TIER_MIXED : j = highest band <= k with applyMode WHOLE
 *               amount = rate(j) × min(base, upper(j)) + Σ_{i=j+1..k} slice(i) × rate(i)
 *               (no WHOLE band reached => same as TIER_SLICE)
 *  Stage rates replace band rates. Monthly cap is applied last. Result rounded 2 dp half-up.
 */
import { CalcMethod, ComponentResult, PlanComponent, TierBand, WorkingLine } from '../types.js';
import { D, Decimal, ZERO, fmt, fmtPct, money2, money4, pct } from '../money.js';

export interface CalcOptions {
  /** Stage key, e.g. "std" or "new". Default "std". */
  stageKey?: string;
  /** Override the component's method (used by "compare methods"). */
  methodOverride?: CalcMethod;
  /** Units for FIXED_PER_UNIT. */
  units?: number;
  /** Negative base carried in from the previous month for this component. */
  carryForwardIn?: string;
  /** If true the raw base is already multiplied by basePct (default false). */
  baseAlreadyAdjusted?: boolean;
}

export function bandRate(band: TierBand, stageKey: string): Decimal {
  const s = band.stageRates?.[stageKey];
  return D(s !== undefined && s !== null && s !== '' ? s : band.ratePct);
}

/** Index of the band that contains `base` (base must be > 0). */
export function findBandIndex(bands: TierBand[], base: Decimal): number {
  for (let i = 0; i < bands.length; i++) {
    const up = bands[i].upperLimit;
    if (up === null || up === '' || base.lte(D(up))) return i;
  }
  return bands.length - 1;
}

function lowerOf(bands: TierBand[], i: number): Decimal {
  return i === 0 ? ZERO : D(bands[i - 1].upperLimit);
}

function bandLabel(bands: TierBand[], i: number): string {
  const lo = lowerOf(bands, i);
  const up = bands[i].upperLimit;
  const from = i === 0 ? '0' : fmt(lo.plus('0.01'));
  return up === null || up === '' ? `above ${fmt(lo)}` : `${from} – ${fmt(up)}`;
}

export function calcComponent(comp: PlanComponent, rawBaseIn: string | Decimal, opts: CalcOptions = {}): ComponentResult {
  const stageKey = opts.stageKey ?? 'std';
  const method = opts.methodOverride ?? comp.method;
  const units = opts.units ?? 0;
  const rawBase = D(rawBaseIn);
  let base = opts.baseAlreadyAdjusted ? rawBase : rawBase.mul(pct(comp.basePct || '100'));
  base = base.plus(D(opts.carryForwardIn ?? '0'));
  const working: WorkingLine[] = [];
  const result: ComponentResult = {
    componentKey: comp.key,
    componentName: comp.name,
    method,
    rawBase: money4(rawBase),
    pooledBase: money4(base),
    units,
    bandIndex: null,
    bandLabel: '—',
    ratePct: null,
    amount: '0.00',
    capped: false,
    nextThreshold: null,
    gapToNext: null,
    carryForwardOut: '0.0000',
    working,
  };

  if (D(comp.basePct || '100').lt(100) && !opts.baseAlreadyAdjusted) {
    working.push(info(`Base ${fmt(rawBase)} × ${fmtPct(comp.basePct)} = ${fmt(rawBase.mul(pct(comp.basePct)))}`));
  }
  if (opts.carryForwardIn && !D(opts.carryForwardIn).isZero()) {
    working.push(info(`Carried forward from last month: ${fmt(opts.carryForwardIn)}`));
  }

  // FIXED_PER_UNIT does not depend on base.
  if (method === 'FIXED_PER_UNIT') {
    const amt = D(comp.fixedAmount ?? '0').mul(units);
    working.push({ from: '', to: '', amount: String(units), ratePct: '', commission: money2(amt), kind: 'FIXED', text: `${units} × S$${fmt(comp.fixedAmount ?? '0')} = ${fmt(amt)}` });
    return finish(comp, result, amt);
  }

  if (base.lte(0)) {
    result.carryForwardOut = money4(base.isNeg() ? base : ZERO);
    working.push(info(base.isNeg() ? `Negative base ${fmt(base)} – no commission, carried to next month` : 'No base this month'));
    return finish(comp, result, ZERO);
  }

  if (method === 'FLAT') {
    const r = D(comp.flatRatePct ?? '0');
    const amt = base.mul(pct(r));
    result.ratePct = r.toString();
    result.bandLabel = 'flat';
    working.push({ from: '0', to: money2(base), amount: money2(base), ratePct: r.toString(), commission: money2(amt), kind: 'FLAT', text: `${fmt(base)} × ${fmtPct(r)} = ${fmt(amt)}` });
    return finish(comp, result, amt);
  }

  const bands = comp.bands;
  if (!bands.length) {
    working.push(info('No tier bands defined'));
    return finish(comp, result, ZERO);
  }
  const k = findBandIndex(bands, base);
  result.bandIndex = k;
  result.bandLabel = bandLabel(bands, k);
  result.ratePct = bandRate(bands[k], stageKey).toString();
  const up = bands[k].upperLimit;
  if (up !== null && up !== '' && k < bands.length - 1) {
    result.nextThreshold = money2(up);
    result.gapToNext = money2(D(up).minus(base).plus('0.01'));
  }

  const modeOf = (i: number): 'WHOLE' | 'SLICE' =>
    method === 'TIER_WHOLE' ? 'WHOLE' : method === 'TIER_SLICE' ? 'SLICE' : bands[i].applyMode ?? 'WHOLE';

  let j = -1;
  for (let i = 0; i <= k; i++) if (modeOf(i) === 'WHOLE') j = i;

  let amt = ZERO;
  if (j >= 0) {
    const covered = j === k ? base : D(bands[j].upperLimit);
    const r = bandRate(bands[j], stageKey);
    const c = covered.mul(pct(r));
    amt = amt.plus(c);
    working.push({ from: '1', to: money2(covered), amount: money2(covered), ratePct: r.toString(), commission: money2(c), kind: 'WHOLE', text: `$1 – ${fmt(covered)} × ${fmtPct(r)} = ${fmt(c)}` });
  }
  for (let i = j + 1; i <= k; i++) {
    const lo = lowerOf(bands, i);
    const hi = i === k ? base : D(bands[i].upperLimit);
    const slice = hi.minus(lo);
    if (slice.lte(0)) continue;
    const r = bandRate(bands[i], stageKey);
    const c = slice.mul(pct(r));
    amt = amt.plus(c);
    working.push({ from: money2(lo), to: money2(hi), amount: money2(slice), ratePct: r.toString(), commission: money2(c), kind: 'SLICE', text: `${fmt(lo)} – ${fmt(hi)} (slice ${fmt(slice)}) × ${fmtPct(r)} = ${fmt(c)}` });
  }
  return finish(comp, result, amt);
}

function finish(comp: PlanComponent, result: ComponentResult, amt: Decimal): ComponentResult {
  let a = amt;
  if (comp.monthlyCap !== undefined && comp.monthlyCap !== null && comp.monthlyCap !== '' && a.gt(D(comp.monthlyCap))) {
    a = D(comp.monthlyCap);
    result.capped = true;
    result.working.push(info(`Capped at S$${fmt(comp.monthlyCap)} per month`, 'CAP'));
  }
  result.amount = money2(a);
  return result;
}

function info(text: string, kind: WorkingLine['kind'] = 'INFO'): WorkingLine {
  return { from: '', to: '', amount: '', ratePct: '', commission: '', kind, text };
}

/** Same base under every tier method (FR-SET-08). Returns [] for non-tier components. */
export function compareMethods(comp: PlanComponent, rawBase: string, stageKey = 'std') {
  if (comp.method === 'FLAT' || comp.method === 'FIXED_PER_UNIT') return [];
  return (['TIER_WHOLE', 'TIER_SLICE', 'TIER_MIXED'] as const).map((m) => ({
    method: m,
    amount: calcComponent(comp, rawBase, { stageKey, methodOverride: m }).amount,
  }));
}

/** Points for the "commission vs monthly base" chart (FR-SET-08). Base here is pooled base. */
export function curve(comp: PlanComponent, method: CalcMethod, maxBase: number, steps = 120, stageKey = 'std') {
  const pts: { base: number; amount: number }[] = [];
  for (let i = 0; i <= steps; i++) {
    const b = (maxBase * i) / steps;
    const r = calcComponent(comp, String(b), { stageKey, methodOverride: method, baseAlreadyAdjusted: true });
    pts.push({ base: b, amount: Number(r.amount) });
  }
  return pts;
}
```

```ts
/**
 * Plan validation before publish (FR-PLN-07, FR-SET-05) and "jump" warnings (FR-SET-09).
 */
import { PlanDefinition } from '../types.js';
import { D, fmt } from '../money.js';
import { bandRate } from './tier.js';

export interface ValidationResult { errors: string[]; warnings: string[] }

export function validatePlan(def: PlanDefinition): ValidationResult {
  const errors: string[] = [];
  const warnings: string[] = [];
  if (!def.components.length) errors.push('A plan needs at least one component.');
  const keys = new Set<string>();
  for (const c of def.components) {
    const p = `Component “${c.name}”`;
    if (keys.has(c.key)) errors.push(`${p}: duplicate key ${c.key}.`);
    keys.add(c.key);
    if (!c.commissionTypes.length) warnings.push(`${p}: no sales types selected – it will always be 0.`);
    const bp = D(c.basePct || '100');
    if (bp.lt(0) || bp.gt(100)) errors.push(`${p}: base % must be 0–100.`);
    if (c.method === 'FLAT') {
      const r = D(c.flatRatePct ?? '0');
      if (r.lt(0) || r.gt(100)) errors.push(`${p}: rate must be 0–100%.`);
    }
    if (c.method === 'FIXED_PER_UNIT' && D(c.fixedAmount ?? '0').lt(0)) errors.push(`${p}: fixed amount cannot be negative.`);
    if (c.method.startsWith('TIER_')) {
      if (!c.bands.length) errors.push(`${p}: add at least one band.`);
      let last = D(0);
      c.bands.forEach((b, i) => {
        const isLast = i === c.bands.length - 1;
        if ((b.upperLimit === null || b.upperLimit === '') && !isLast) errors.push(`${p}: only the last band may have no upper limit.`);
        if (b.upperLimit !== null && b.upperLimit !== '') {
          if (D(b.upperLimit).lte(last)) errors.push(`${p}: band limits must increase (band ${i + 1}).`);
          last = D(b.upperLimit);
        }
        const rates = [b.ratePct, ...Object.values(b.stageRates ?? {}).filter((x): x is string => !!x)];
        if (rates.some((r) => D(r).lt(0) || D(r).gt(100))) errors.push(`${p}: band ${i + 1} rate must be 0–100%.`);
      });
      if (c.method === 'TIER_WHOLE') {
        const jumps: string[] = [];
        for (let i = 1; i < c.bands.length; i++) {
          const lim = c.bands[i - 1].upperLimit;
          if (!lim) continue;
          const jump = D(lim).mul(bandRate(c.bands[i], 'std').minus(bandRate(c.bands[i - 1], 'std'))).div(100);
          if (jump.gte(100)) jumps.push(`+S$${fmt(jump)} at S$${fmt(lim)}`);
        }
        if (jumps.length) warnings.push(`${p}: whole-amount tiers make commission jump when sales pass a band limit (${jumps.join(', ')}). Use “Mixed” or “By slice” if this is not intended.`);
      }
    }
  }
  const sk = new Set<string>();
  for (const s of def.stages) {
    if (sk.has(s.key)) errors.push(`Duplicate stage key ${s.key}.`);
    sk.add(s.key);
    if (s.fromMonth < 1) errors.push(`Stage “${s.name}” must start at month 1 or later.`);
    if (s.toMonth !== null && s.toMonth < s.fromMonth) errors.push(`Stage “${s.name}”: end month before start month.`);
  }
  for (const r of def.incentives) {
    if (r.type === 'GROUP_AND_INDIVIDUAL' && r.rows.some((x) => !x.groupTarget)) errors.push(`Incentive “${r.name}”: every row needs a group target.`);
  }
  return { errors, warnings };
}
```

```ts
/**
 * Money helpers. NEVER use JS numbers for money – always Decimal.
 * Storage precision: base lines 4 dp; statement amounts 2 dp, ROUND_HALF_UP (NFR-01).
 */
import Decimal from 'decimal.js';

Decimal.set({ precision: 40, rounding: Decimal.ROUND_HALF_UP });

export { Decimal };
export type DecimalLike = Decimal | string | number;

export const D = (v: DecimalLike | null | undefined): Decimal => new Decimal(v ?? 0);
export const ZERO = new Decimal(0);

/** Round to 2 dp half-up and return a fixed string, e.g. "628.99". */
export const money2 = (v: DecimalLike): string => D(v).toDecimalPlaces(2, Decimal.ROUND_HALF_UP).toFixed(2);
/** Round to 4 dp (ledger precision). */
export const money4 = (v: DecimalLike): string => D(v).toDecimalPlaces(4, Decimal.ROUND_HALF_UP).toFixed(4);

/** Percentage helper: pct("7") => 0.07 */
export const pct = (ratePct: DecimalLike): Decimal => D(ratePct).div(100);

/** Display helper: 8985.5 => "8,985.50" */
export const fmt = (v: DecimalLike): string => {
  const s = money2(v);
  const neg = s.startsWith('-');
  const [i, f] = (neg ? s.slice(1) : s).split('.');
  return (neg ? '-' : '') + i.replace(/\B(?=(\d{3})+(?!\d))/g, ',') + '.' + f;
};

/** Format a rate for display: "7" -> "7%", "2.50" -> "2.5%" */
export const fmtPct = (v: DecimalLike): string => D(v).toDecimalPlaces(4).toString() + '%';

/**
 * Split an amount between staff by split % so that the parts add up EXACTLY to the amount
 * (at 4 dp). The last staff member receives the rounding remainder.
 */
export function allocateBySplit<T extends { splitPct: DecimalLike }>(amount: DecimalLike, splits: T[]): { split: T; amount: string }[] {
  if (splits.length === 0) throw new Error('At least one staff split is required');
  const total = splits.reduce((s, x) => s.plus(D(x.splitPct)), ZERO);
  if (!total.eq(100)) throw new Error(`Split % must total 100 (got ${total.toString()})`);
  const amt = D(amount);
  let used = ZERO;
  return splits.map((split, i) => {
    const part = i === splits.length - 1 ? amt.minus(used) : amt.mul(pct(split.splitPct)).toDecimalPlaces(4, Decimal.ROUND_HALF_UP);
    used = used.plus(part);
    return { split, amount: money4(part) };
  });
}
```

```ts
/**
 * Glampro Commission – shared domain types.
 *
 * RULES (read before changing anything – see AI_HANDOFF.md):
 *  - Money is ALWAYS a decimal string in the API / DB layer ("1234.50"), never a JS float.
 *    Inside the engine we use Decimal (decimal.js). See money.ts.
 *  - Rates are percentages as decimal strings: "7" means 7%, "2.5" means 2.5%.
 *  - Dates are ISO strings: "YYYY-MM-DD" for business dates, full ISO for timestamps.
 *  - These types are shared by backend (Node) and frontend (React). Keep them framework-free.
 *
 * Requirement IDs (FR-xxx) refer to "Glampro SRS – Staff Commission Plans v1.2".
 */

/** Kind of commissionable event written to the base ledger (SRS §1.3, FR-BAS). */
export type CommissionType =
  | 'SVC' //       cash service (service paid normally, not from a package)
  | 'PRD' //       product sale
  | 'PKG_SALE' //  package sale – CASH COLLECTED (deposit / instalment / full), negative on refund
  | 'PKG_RED' //   package redemption ("on course") – session value
  | 'FOC' //       complimentary service – service list price (component applies base %)
  | 'VP_SALE' //   value (stored-credit) package sale – cash paid
  | 'VP_SPEND' //  service paid with stored credit – credit × paid/credit ratio
  | 'GC_SALE'; //  gift card sale (excluded from seed plans)

export const COMMISSION_TYPE_LABELS: Record<CommissionType, string> = {
  SVC: 'Cash service',
  PRD: 'Product',
  PKG_SALE: 'Package sale (cash collected)',
  PKG_RED: 'On course (redemption)',
  FOC: 'FOC service',
  VP_SALE: 'Value package sale',
  VP_SPEND: 'Value package spend',
  GC_SALE: 'Gift card sale',
};

/**
 * How a component turns its pooled monthly base into commission (FR-PLN-03, FR-CAL-04).
 *  FLAT            base × flatRatePct
 *  TIER_WHOLE      rate of the band reached × whole base ("retroactive")
 *  TIER_SLICE      each band's rate on its own slice ("progressive", like income tax)
 *  TIER_MIXED      per band: applyMode WHOLE (from $1 up to its limit) or SLICE
 *  FIXED_PER_UNIT  fixedAmount × number of units (e.g. S$5 per FOC service)
 */
export type CalcMethod = 'FLAT' | 'TIER_WHOLE' | 'TIER_SLICE' | 'TIER_MIXED' | 'FIXED_PER_UNIT';

export const CALC_METHOD_LABELS: Record<CalcMethod, { title: string; help: string }> = {
  FLAT: { title: 'Flat %', help: 'One rate on everything' },
  TIER_WHOLE: { title: 'Tier – whole amount', help: 'Band reached × whole base (retroactive)' },
  TIER_SLICE: { title: 'Tier – by slice', help: 'Each band only on its own slice (progressive)' },
  TIER_MIXED: { title: 'Tier – mixed', help: 'Choose per band: from $1 or slice only' },
  FIXED_PER_UNIT: { title: 'Fixed $ per unit', help: 'Fixed amount × number of items' },
};

export type ApplyMode = 'WHOLE' | 'SLICE';

/** One row of a tier table (FR-PLN-04). Band i covers base > upperLimit(i-1) and <= upperLimit(i). */
export interface TierBand {
  /** null = no upper limit (only allowed on the last band). */
  upperLimit: string | null;
  /** Rate for the Standard stage, e.g. "8". */
  ratePct: string;
  /** Optional rate per stage key, e.g. { new: "4" }. Missing / null = same as ratePct. */
  stageRates?: Record<string, string | null>;
  /** Only used when method = TIER_MIXED. Default WHOLE. */
  applyMode?: ApplyMode;
}

/** Tenure stage, e.g. New staff months 1–3 (FR-STG-01). */
export interface PlanStage {
  key: string; // stable key used in stageRates, e.g. "new", "std"
  name: string;
  fromMonth: number; // 1-based tenure month
  toMonth: number | null; // null = open-ended
}

export interface PlanComponent {
  key: string; // stable key, e.g. "cash_pkg"
  name: string;
  commissionTypes: CommissionType[];
  /** If set, only base lines whose productCategory is in this list count. */
  categoryInclude?: string[];
  /** If set, base lines whose productCategory is in this list are excluded. */
  categoryExclude?: string[];
  /** Share of the base that counts, e.g. "50" for FOC at 50% of price. Default "100". */
  basePct: string;
  method: CalcMethod;
  flatRatePct?: string;
  fixedAmount?: string;
  /** Optional maximum commission per month for this component. */
  monthlyCap?: string | null;
  bands: TierBand[];
  sort: number;
}

export interface IncentiveRow {
  /** Required for GROUP_AND_INDIVIDUAL, ignored for INDIVIDUAL_TARGET. */
  groupTarget?: string | null;
  individualTarget: string;
  amount: string;
}

export interface IncentiveRule {
  key: string;
  name: string;
  type: 'INDIVIDUAL_TARGET' | 'GROUP_AND_INDIVIDUAL';
  /** Commission types summed for the staff member's individual metric (FR-INC-03). */
  individualMetricTypes: CommissionType[];
  /** How the group metric is measured (FR-INC-04). */
  groupMetric: 'SALON_CASH' | 'SUM_INDIVIDUAL';
  rows: IncentiveRow[];
}

/** The rules of one plan version (stored as JSON in plan_version.definition). */
export interface PlanDefinition {
  stages: PlanStage[];
  components: PlanComponent[];
  incentives: IncentiveRule[];
}

export interface PlanVersion {
  id: string;
  planId: string;
  versionNo: number;
  effectiveFrom: string; // YYYY-MM-DD
  reason: string;
  status: 'DRAFT' | 'PUBLISHED';
  definition: PlanDefinition;
  publishedBy?: string | null;
  publishedAt?: string | null;
}

export interface CommissionPlan {
  id: string;
  salonId: string;
  name: string;
  description?: string;
  positions: string[];
  status: 'ACTIVE' | 'ARCHIVED';
}

/** One row of the append-only Commission Base Ledger (FR-BAS-01). */
export interface BaseLine {
  id: string;
  salonId: string;
  staffId: string;
  commissionType: CommissionType;
  productCategory?: string | null;
  /** Amount credited to THIS staff member (already multiplied by split). Can be negative (refund). */
  baseAmount: string;
  splitPct: string;
  /** Units for FIXED_PER_UNIT components (usually 1, -1 on reversal). */
  units: number;
  /**
   * Package-level "Fixed $" commission (FR-CAL-08). When set, this line is NOT pooled into plan
   * components; the fixed amount is paid as its own result line ("Package fixed commission").
   */
  fixedCommission?: string | null;
  businessDate: string; // YYYY-MM-DD in salon time zone
  sourceType: 'SALE_LINE' | 'PAYMENT' | 'SESSION_USAGE' | 'REFUND' | 'CORRECTION';
  sourceId: string;
  /** Package holding this line belongs to (package sale / redemption / refund), else null. */
  holdingId?: string | null;
  status: 'EARNED' | 'REVERSED' | 'PAID';
  reversedById?: string | null;
  reason?: string | null;
  createdBy: string;
  createdAt: string;
}

export interface StaffSplit {
  staffId: string;
  splitPct: string; // "50"
}

/** One working line shown to the admin, e.g. "$1 – 8,985.50 × 7% = 628.99". */
export interface WorkingLine {
  from: string;
  to: string;
  amount: string; // base covered
  ratePct: string;
  commission: string;
  kind: 'WHOLE' | 'SLICE' | 'FLAT' | 'FIXED' | 'CAP' | 'INFO';
  text: string;
}

export interface ComponentResult {
  componentKey: string;
  componentName: string;
  method: CalcMethod;
  rawBase: string; // before base %
  pooledBase: string; // after base %
  units: number;
  bandIndex: number | null;
  bandLabel: string;
  ratePct: string | null; // rate of band reached (or flat rate)
  amount: string; // rounded 2dp
  capped: boolean;
  /** Base needed above which the next band starts (null if top band / flat). */
  nextThreshold: string | null;
  gapToNext: string | null;
  carryForwardOut: string; // negative base carried to next month (0 if none)
  working: WorkingLine[];
}

export interface IncentiveResult {
  ruleKey: string;
  name: string;
  individualMetric: string;
  groupMetric: string | null;
  rowIndex: number | null;
  amount: string;
}

export interface StaffPeriodResult {
  staffId: string;
  periodKey: string; // "2026-09"
  planId: string | null;
  planVersionId: string | null;
  tenureMonth: number | null;
  stageKey: string;
  stageName: string;
  components: ComponentResult[];
  incentives: IncentiveResult[];
  commissionTotal: string;
  incentiveTotal: string;
}
```

```prisma
// Glampro commission module – PostgreSQL schema (SRS v1.2 §6).
// All tables are prefixed "comm_" so they sit beside Glampro's existing tables without clashing.
// Ids are strings so you can store Glampro's existing ids (staff, holding, customer) directly.
// Money: Decimal(14,4) for ledger amounts, Decimal(12,2) for statement amounts. Never Float.

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model CommPlan {
  id          String           @id
  salonId     String
  name        String
  description String?
  positions   String[]
  status      String           @default("ACTIVE") // ACTIVE | ARCHIVED
  createdAt   DateTime         @default(now())
  updatedAt   DateTime         @updatedAt
  versions    CommPlanVersion[]

  @@index([salonId])
  @@map("comm_plan")
}

model CommPlanVersion {
  id            String    @id
  planId        String
  plan          CommPlan  @relation(fields: [planId], references: [id])
  versionNo     Int
  effectiveFrom String // YYYY-MM-DD
  reason        String
  status        String // DRAFT | PUBLISHED
  /// PlanDefinition JSON: { stages, components (with bands), incentives } – see shared/src/types.ts
  definition    Json
  publishedBy   String?
```

```ts
/**
 * Express REST API for the commission module. Mount under /api/commission in Glampro:
 *     app.use('/api/commission', createCommissionRouter(repo));
 *
 * AUTH: `actorFrom()` below reads demo headers (x-salon-id, x-user-id, x-role).
 * Replace it with Glampro's real session / JWT middleware (see AI_HANDOFF.md §4).
 */
import cors from 'cors';
import express, { NextFunction, Request, Response, Router } from 'express';
import { ZodError, ZodTypeAny, z } from 'zod';
import type { CommissionRepo } from '../repo/types.js';
import { LedgerService } from '../services/ledgerService.js';
import { PeriodService } from '../services/periodService.js';
import { PlanService } from '../services/planService.js';
import { StaffService } from '../services/staffService.js';
import { Actor, AppError, forbidden } from '../services/util.js';
import { periodKey, schemas } from './schemas.js';

function actorFrom(req: Request): Actor {
  const salonId = String(req.header('x-salon-id') ?? '');
  const userId = String(req.header('x-user-id') ?? '');
  const role = String(req.header('x-role') ?? 'STAFF') as Actor['role'];
  if (!salonId || !userId) throw new AppError(401, 'UNAUTHENTICATED', 'Missing salon / user');
  if (!['SUPER_ADMIN', 'MANAGER', 'STAFF', 'CASHIER'].includes(role)) throw forbidden('Unknown role');
  return { salonId, userId, role };
}

const body = <S extends ZodTypeAny>(schema: S, req: Request): z.infer<S> => schema.parse(req.body);
type H = (req: Request, res: Response) => Promise<unknown>;
const h = (fn: H) => (req: Request, res: Response, next: NextFunction) => fn(req, res).then((data) => { if (!res.headersSent) res.json(data); }).catch(next);

export function createCommissionRouter(repo: CommissionRepo): Router {
  const r = Router();
  const plans = new PlanService(repo);
  const ledger = new LedgerService(repo);
  const periods = new PeriodService(repo);
  const staff = new StaffService(repo);
  const managerOnly = (a: Actor) => { if (a.role !== 'SUPER_ADMIN' && a.role !== 'MANAGER') throw forbidden(); };

  // ---- dashboard & settings (FR-SET-01) ----
  r.get('/overview', h(async (req) => staff.overview(actorFrom(req).salonId, req.query.period ? periodKey.parse(req.query.period) : undefined)));
  r.get('/settings', h(async (req) => repo.getSettings(actorFrom(req).salonId)));
  r.put('/settings', h(async (req) => {
    const a = actorFrom(req);
    if (a.role !== 'SUPER_ADMIN') throw forbidden();
    return repo.saveSettings({ ...body(schemas.settings, req), salonId: a.salonId });
  }));

  // ---- plans (FR-PLN, FR-SET) ----
  r.get('/plans', h(async (req) => plans.list(actorFrom(req).salonId)));
  r.post('/plans', h(async (req) => plans.create(actorFrom(req), body(schemas.createPlan, req))));
  r.get('/plans/:planId', h(async (req) => plans.get(req.params.planId)));
  r.patch('/plans/:planId', h(async (req) => plans.update(actorFrom(req), req.params.planId, body(schemas.updatePlan, req))));
  r.put('/plans/:planId/draft', h(async (req) => plans.saveDraft(actorFrom(req), req.params.planId, body(schemas.saveDraft, req).definition)));
  r.post('/versions/:versionId/publish', h(async (req) => { const b = body(schemas.publish, req); return plans.publish(actorFrom(req), req.params.versionId, b.effectiveFrom, b.reason); }));
  r.post('/simulate', h(async (req) => { actorFrom(req); const b = body(schemas.simulate, req); return plans.simulate(b.component, b.base, b.stageKey, b.units); }));
  r.post('/plans/:planId/impact', h(async (req) => { const b = body(schemas.impact, req); return plans.impact(actorFrom(req), req.params.planId, b.definition, b.periodKey); }));

  // ---- staff (FR-ASN, FR-STG-04, FR-PAY-02) ----
  r.get('/staff/:staffId', h(async (req) => staff.commissionProfile(actorFrom(req).salonId, req.params.staffId)));
  r.post('/staff/:staffId/assignments', h(async (req) => staff.assignPlan(actorFrom(req), req.params.staffId, body(schemas.assign, req))));
  r.put('/staff/:staffId/stage-override', h(async (req) => { const b = body(schemas.stageOverride, req); return staff.setStageOverride(actorFrom(req), req.params.staffId, b.endMonth, b.reason); }));
  r.put('/staff/:staffId/payroll-profile', h(async (req) => staff.savePayrollProfile(actorFrom(req), { ...body(schemas.payrollProfile, req), staffId: req.params.staffId })));

  // ---- POS hooks / ledger (FR-BAS, FR-POS, FR-ADJ) ----
  r.post('/holdings', h(async (req) => ledger.purchasePackage(actorFrom(req), body(schemas.purchasePackage, req))));
  r.get('/holdings/:holdingId', h(async (req) => ledger.holdingDetail(actorFrom(req).salonId, req.params.holdingId)));
  r.post('/holdings/:holdingId/payments', h(async (req) => ledger.collectPayment(actorFrom(req), { ...body(schemas.collectPayment, req), holdingId: req.params.holdingId })));
  r.post('/holdings/:holdingId/redeem', h(async (req) => ledger.redeemSession(actorFrom(req), { ...body(schemas.redeem, req), holdingId: req.params.holdingId })));
  r.post('/holdings/:holdingId/refund', h(async (req) => ledger.refundPackage(actorFrom(req), { ...body(schemas.refund, req), holdingId: req.params.holdingId })));
  r.post('/sessions/:sessionUsageId/void', h(async (req) => ledger.voidSession(actorFrom(req), { ...body(schemas.voidSession, req), sessionUsageId: req.params.sessionUsageId })));
  r.post('/lines/:lineId/correct-staff', h(async (req) => ledger.correctStaff(actorFrom(req), { ...body(schemas.correctStaff, req), lineId: req.params.lineId })));
  r.post('/lines/service', h(async (req) => ledger.recordService(actorFrom(req), body(schemas.service, req))));
  r.post('/lines/product', h(async (req) => ledger.recordProduct(actorFrom(req), body(schemas.product, req))));
  r.post('/lines/value-package', h(async (req) => ledger.recordValuePackage(actorFrom(req), body(schemas.valuePackage, req))));
  r.get('/lines', h(async (req) => {
    const a = actorFrom(req);
    const staffId = req.query.staffId ? String(req.query.staffId) : undefined;
    if (a.role === 'STAFF' && staffId !== a.userId) throw forbidden('Staff can only see their own lines');
    return repo.listLines({ salonId: a.salonId, staffId, from: req.query.from as string | undefined, to: req.query.to as string | undefined, includeReversed: req.query.includeReversed === 'true' });
  }));

  // ---- periods & payroll (FR-CAL, FR-PAY, FR-RPT) ----
  r.post('/periods/:periodKey/calculate', h(async (req) => periods.calculate(actorFrom(req), periodKey.parse(req.params.periodKey))));
  r.get('/periods/:periodKey', h(async (req) => { const a = actorFrom(req); managerOnly(a); return periods.summary(a.salonId, periodKey.parse(req.params.periodKey)); }));
  r.get('/periods/:periodKey/staff/:staffId', h(async (req) => {
    const a = actorFrom(req);
    if (a.role === 'STAFF' && a.userId !== req.params.staffId) throw forbidden('Staff can only see their own statement');
    return periods.statement(a.salonId, periodKey.parse(req.params.periodKey), req.params.staffId);
  }));
  r.post('/periods/:periodKey/adjustments', h(async (req) => periods.addAdjustment(actorFrom(req), { ...body(schemas.adjustment, req), periodKey: periodKey.parse(req.params.periodKey) })));
  r.post('/periods/:periodKey/approve', h(async (req) => periods.approve(actorFrom(req), periodKey.parse(req.params.periodKey))));
  r.get('/periods/:periodKey/export.csv', async (req, res, next) => {
    try {
      const a = actorFrom(req);
      managerOnly(a);
      const key = periodKey.parse(req.params.periodKey);
      res.setHeader('Content-Type', 'text/csv; charset=utf-8');
      res.setHeader('Content-Disposition', `attachment; filename="commission-${key}.csv"`);
      res.send('﻿' + (await periods.exportCsv(a.salonId, key)));
    } catch (e) { next(e); }
  });

  r.use((err: unknown, _req: Request, res: Response, _next: NextFunction) => {
    if (err instanceof ZodError) return res.status(400).json({ code: 'VALIDATION', message: 'Invalid request', details: err.issues });
    if (err instanceof AppError) return res.status(err.status).json({ code: err.code, message: err.message, details: err.details });
    console.error(err);
    return res.status(500).json({ code: 'SERVER_ERROR', message: (err as Error)?.message ?? 'Unexpected error' });
  });
  return r;
}

export function createApp(repo: CommissionRepo) {
  const app = express();
  app.use(cors());
  app.use(express.json({ limit: '1mb' }));
  app.get('/health', (_req, res) => res.json({ ok: true }));
  app.use('/api/commission', createCommissionRouter(repo));
  app.use((_req, res) => res.status(404).json({ code: 'NOT_FOUND', message: 'Unknown route' }));
  return app;
}
```

```ts
  }
```

## backend/src/services/ledgerService.ts

```ts
/**
 * Commission Base Ledger – the hooks Glampro's POS calls when money or sessions move (FR-BAS, FR-POS, FR-ADJ).
 *
 * Integration (see AI_HANDOFF.md §4): after Glampro completes a checkout, call the matching method
 * with the Glampro ids. Each call writes base lines (NO rates) – rates are applied at month end.
 *
 *   purchasePackage()    package line sold (creates commission holding + first payment)
 *   collectPayment()     later deposit / instalment / balance for a package          -> PKG_SALE
 *   redeemSession()      one session used (D-8 paid-sessions rule enforced)          -> PKG_RED
 *   recordService()      cash service / FOC                                          -> SVC / FOC
 *   recordProduct()      product sold                                                -> PRD
 *   recordValuePackage() value package sale / spend                                  -> VP_SALE / VP_SPEND
 *   refundPackage()      D-7: negative PKG_SALE on refunded part only               -> PKG_SALE (negative)
 *   voidSession()        reverse a redemption, session returned
 *   correctStaff()       move a line to the right staff member
 */
import {
  BaseLine, CommissionType, D, StaffSplit, allocateBySplit, canRedeem, minDeposit, money2, money4, refundAmount, sessionValue,
  valuePackageSpendBase,
} from '@glampro/commission-shared';
import type { CommissionMode, CommissionRepo, HoldingCommission, SessionUsage } from '../repo/types.js';
import { Actor, AppError, badRequest, conflict, forbidden, newId, notFound, nowIso, periodKeyOf, nextPeriodKey } from './util.js';

export interface PurchasePackageInput {
  holdingId: string; // Glampro holding id
  customerId: string;
  packageId: string;
  packageName: string;
  netPrice: string; // after discount, excl. GST
  sessions: number;
  sellers: StaffSplit[];
  payNow: string; // full amount or deposit
  paymentId: string;
  businessDate: string;
  minDepositPct?: string;
  saleCommMode?: CommissionMode;
  saleFixedAmount?: string | null;
  redCommMode?: CommissionMode;
  redFixedAmount?: string | null;
}

export class LedgerService {
  constructor(private repo: CommissionRepo) {}

  // ---------- helpers ----------
  private validateSplits(splits: StaffSplit[], what: string) {
    if (!splits?.length) throw badRequest(`${what}: at least one staff member is required`);
    if (splits.length > 4) throw badRequest(`${what}: maximum 4 staff per line`);
    const total = splits.reduce((s, x) => s.plus(D(x.splitPct)), D(0));
    if (!total.eq(100)) throw badRequest(`${what}: split % must total 100`);
  }

  /** If the business date's period is approved (locked), post to the next open period (FR-PAY-06). */
  private async openDate(salonId: string, businessDate: string): Promise<string> {
    let key = periodKeyOf(businessDate);
    let date = businessDate;
    for (let i = 0; i < 24; i++) {
      const p = await this.repo.getPeriod(salonId, key);
      if (p?.status !== 'APPROVED') return date;
      key = nextPeriodKey(key);
      date = `${key}-01`;
    }
    throw conflict('No open commission period found');
  }

  private makeLines(actor: Actor, args: {
    splits: StaffSplit[]; amount: string; type: CommissionType; businessDate: string; sourceType: BaseLine['sourceType']; sourceId: string;
    productCategory?: string | null; units?: number; fixedCommission?: string | null; reason?: string | null; holdingId?: string | null;
  }): BaseLine[] {
    const parts = allocateBySplit(args.amount, args.splits);
    const fixedParts = args.fixedCommission != null ? allocateBySplit(args.fixedCommission, args.splits) : null;
    return parts.map((p, i) => ({
      id: newId('cbl'),
      salonId: actor.salonId,
      staffId: p.split.staffId,
      commissionType: args.type,
      productCategory: args.productCategory ?? null,
      baseAmount: p.amount,
      splitPct: p.split.splitPct,
      units: args.units ?? 1,
      fixedCommission: fixedParts ? fixedParts[i].amount : null,
      businessDate: args.businessDate,
      sourceType: args.sourceType,
      sourceId: args.sourceId,
      holdingId: args.holdingId ?? null,
      status: 'EARNED',
      reversedById: null,
      reason: args.reason ?? null,
      createdBy: actor.userId,
      createdAt: nowIso(),
    }));
  }

  // ---------- packages ----------
  async purchasePackage(actor: Actor, i: PurchasePackageInput) {
    if (await this.repo.getHolding(i.holdingId)) throw conflict('Holding already registered');
    this.validateSplits(i.sellers, 'Sold by');
    if (D(i.netPrice).lte(0)) throw badRequest('Package price must be greater than 0');
    if (D(i.payNow).lte(0) || D(i.payNow).gt(D(i.netPrice))) throw badRequest('Pay-now amount must be > 0 and not more than the price');
    const settings = await this.repo.getSettings(actor.salonId);
    const minPct = i.minDepositPct ?? settings.defaultMinDepositPct;
    const min = minDeposit(i.netPrice, minPct);
    if (D(i.payNow).lt(D(min))) throw badRequest(`Minimum deposit is S$${min} (${minPct}%)`);

    const holding: HoldingCommission = {
      id: i.holdingId, salonId: actor.salonId, customerId: i.customerId, packageId: i.packageId, packageName: i.packageName,
      netPrice: money2(i.netPrice), sessionsTotal: i.sessions, sessionsUsed: 0, sessionValue: sessionValue(i.netPrice, i.sessions),
      cashCollected: '0.00', sellers: i.sellers, saleCommMode: i.saleCommMode ?? 'FOLLOW_PLAN', saleFixedAmount: i.saleFixedAmount ?? null,
      redCommMode: i.redCommMode ?? 'FOLLOW_PLAN', redFixedAmount: i.redFixedAmount ?? null, status: 'ACTIVE', createdAt: nowIso(),
    };
    await this.repo.saveHolding(holding);
    const pay = await this.collectPayment(actor, { holdingId: i.holdingId, amount: i.payNow, paymentId: i.paymentId, businessDate: i.businessDate }, true);
    return { holding: pay.holding, lines: pay.lines };
  }

  /** Deposit / instalment / balance – PKG_SALE base = cash collected (D-1, FR-BAS-04, FR-POS-05). */
  async collectPayment(actor: Actor, i: { holdingId: string; amount: string; paymentId: string; businessDate: string }, first = false) {
    const h = await this.repo.getHolding(i.holdingId);
    if (!h) throw notFound('Holding');
    if (h.status !== 'ACTIVE') throw conflict(`Holding is ${h.status}`);
    const balance = D(h.netPrice).minus(D(h.cashCollected));
    if (D(i.amount).lte(0) || D(i.amount).gt(balance)) throw badRequest(`Amount must be > 0 and not more than the balance S$${money2(balance)}`);
    const date = await this.openDate(actor.salonId, i.businessDate);
    let lines: BaseLine[] = [];
    if (h.saleCommMode !== 'EXCLUDE') {
      lines = this.makeLines(actor, {
        splits: h.sellers, amount: i.amount, type: 'PKG_SALE', businessDate: date, sourceType: 'PAYMENT', sourceId: i.paymentId, holdingId: h.id,
        fixedCommission: h.saleCommMode === 'FIXED' ? (first ? h.saleFixedAmount ?? '0' : '0') : null,
      });
      await this.repo.insertLines(lines);
    }
    h.cashCollected = money2(D(h.cashCollected).plus(D(i.amount)));
    await this.repo.saveHolding(h);
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'PKG_PAYMENT', entity: 'holding', entityId: h.id, after: { amount: i.amount, paymentId: i.paymentId } });
    return { holding: h, lines };
  }

  /** D-8: only paid-for sessions can be redeemed; manager PIN override is logged (FR-POS-08). */
  async redeemSession(actor: Actor, i: {
    holdingId: string; performers: StaffSplit[]; businessDate: string; serviceId?: string | null; appointmentId?: string | null;
    override?: { managerId: string; reason: string } | null;
  }) {
    const h = await this.repo.getHolding(i.holdingId);
    if (!h) throw notFound('Holding');
    if (h.status !== 'ACTIVE') throw conflict(`Holding is ${h.status}`);
    this.validateSplits(i.performers, 'Performed by');
    const check = canRedeem(h);
    if (!check.ok) {
      const canOverride = h.sessionsUsed < h.sessionsTotal && !!i.override?.managerId && !!i.override?.reason;
      if (!canOverride) throw new AppError(409, 'SESSION_NOT_PAID', check.reason ?? 'Cannot redeem', { paidSessions: check.paid });
    }
    const date = await this.openDate(actor.salonId, i.businessDate);
    const usage: SessionUsage = {
      id: newId('su'), holdingId: h.id, usedAt: nowIso(), businessDate: date, serviceId: i.serviceId ?? null, appointmentId: i.appointmentId ?? null,
      sessionValue: h.sessionValue, performers: i.performers, overrideBy: check.ok ? null : i.override!.managerId,
      overrideReason: check.ok ? null : i.override!.reason, voidedAt: null, voidReason: null,
    };
    await this.repo.saveSessionUsage(usage);
    let lines: BaseLine[] = [];
    if (h.redCommMode !== 'EXCLUDE') {
      lines = this.makeLines(actor, {
        splits: i.performers, amount: h.sessionValue, type: 'PKG_RED', businessDate: date, sourceType: 'SESSION_USAGE', sourceId: usage.id, holdingId: h.id,
        fixedCommission: h.redCommMode === 'FIXED' ? h.redFixedAmount ?? '0' : null,
      });
      await this.repo.insertLines(lines);
    }
    h.sessionsUsed += 1;
    if (h.sessionsUsed >= h.sessionsTotal) h.status = 'COMPLETED';
    await this.repo.saveHolding(h);
    if (!check.ok) await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'REDEEM_OVERRIDE', entity: 'holding', entityId: h.id, reason: i.override!.reason, after: { managerId: i.override!.managerId } });
    return { usage, lines, holding: h, sessionsLeft: h.sessionsTotal - h.sessionsUsed };
  }

  /** D-7: refund takes back only the sale commission on the refunded part; redemption stays (FR-ADJ-01/02). */
  async refundPackage(actor: Actor, i: { holdingId: string; refundId: string; businessDate: string; reason: string; adminFee?: string }) {
    this.requireManager(actor);
    if (!i.reason?.trim()) throw badRequest('Refund reason is required');
    const h = await this.repo.getHolding(i.holdingId);
    if (!h) throw notFound('Holding');
    if (h.status === 'REFUNDED') throw conflict('Already refunded');
    const settings = await this.repo.getSettings(actor.salonId);
    const amount = refundAmount(h.cashCollected, h.sessionsUsed, h.sessionValue, i.adminFee ?? settings.refundAdminFee);
    const date = await this.openDate(actor.salonId, i.businessDate);
    let lines: BaseLine[] = [];
    if (D(amount).gt(0) && h.saleCommMode !== 'EXCLUDE') {
      lines = this.makeLines(actor, { splits: h.sellers, amount: money4(D(amount).neg()), type: 'PKG_SALE', businessDate: date, sourceType: 'REFUND', sourceId: i.refundId, holdingId: h.id, reason: i.reason, fixedCommission: h.saleCommMode === 'FIXED' ? '0' : null });
      await this.repo.insertLines(lines);
    }
    h.cashCollected = money2(D(h.cashCollected).minus(D(amount)));
    h.status = 'REFUNDED';
    await this.repo.saveHolding(h);
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'PKG_REFUND', entity: 'holding', entityId: h.id, after: { amount }, reason: i.reason });
    return { refundAmount: amount, lines, holding: h };
  }

  /** FR-ADJ-03: reverse a redemption and return the session. */
  async voidSession(actor: Actor, i: { sessionUsageId: string; reason: string; businessDate: string }) {
    this.requireManager(actor);
    if (!i.reason?.trim()) throw badRequest('Reason is required');
    const s = await this.repo.getSessionUsage(i.sessionUsageId);
    if (!s) throw notFound('Session');
    if (s.voidedAt) throw conflict('Session already voided');
    const lines = await this.repo.listLines({ salonId: actor.salonId, sourceId: s.id });
    const reversals = await this.reverseLines(actor, lines, i.reason, i.businessDate);
    s.voidedAt = nowIso();
    s.voidReason = i.reason;
    await this.repo.saveSessionUsage(s);
    const h = await this.repo.getHolding(s.holdingId);
    if (h) {
      h.sessionsUsed = Math.max(0, h.sessionsUsed - 1);
      if (h.status === 'COMPLETED') h.status = 'ACTIVE';
      await this.repo.saveHolding(h);
    }
    return { session: s, reversals };
  }

  /** FR-ADJ-04: move a base line to the correct staff member. */
  async correctStaff(actor: Actor, i: { lineId: string; newStaffId: string; reason: string; businessDate: string }) {
    this.requireManager(actor);
    if (!i.reason?.trim()) throw badRequest('Reason is required');
    const l = await this.repo.getLine(i.lineId);
    if (!l) throw notFound('Line');
    if (l.status === 'REVERSED') throw conflict('Line already reversed');
    const reversals = await this.reverseLines(actor, [l], i.reason, i.businessDate);
    const date = reversals.posted.length ? reversals.posted[0].businessDate : l.businessDate;
    const repost: BaseLine = { ...l, id: newId('cbl'), staffId: i.newStaffId, businessDate: date, status: 'EARNED', reversedById: null, sourceType: 'CORRECTION', reason: i.reason, createdBy: actor.userId, createdAt: nowIso() };
    await this.repo.insertLines([repost]);
    return { reversals, repost };
  }

  /**
   * Reverse lines: if the line's period is still open -> mark REVERSED.
   * If approved (locked) -> post a negative copy in the next open period (FR-PAY-06).
   */
  private async reverseLines(actor: Actor, lines: BaseLine[], reason: string, businessDate: string) {
    const marked: string[] = [];
    const posted: BaseLine[] = [];
    for (const l of lines) {
      const p = await this.repo.getPeriod(actor.salonId, periodKeyOf(l.businessDate));
      if (p?.status === 'APPROVED') {
        const neg: BaseLine = {
          ...l, id: newId('cbl'), baseAmount: money4(D(l.baseAmount).neg()), units: -(l.units ?? 0),
          fixedCommission: l.fixedCommission != null ? money4(D(l.fixedCommission).neg()) : null,
          businessDate: await this.openDate(actor.salonId, businessDate), sourceType: 'CORRECTION', status: 'EARNED', reason, createdBy: actor.userId, createdAt: nowIso(),
        };
        await this.repo.insertLines([neg]);
        posted.push(neg);
      } else {
        await this.repo.updateLineStatus(l.id, 'REVERSED');
        marked.push(l.id);
      }
    }
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'LINES_REVERSE', entity: 'base_line', entityId: lines.map((x) => x.id).join(','), reason });
    return { marked, posted };
  }

  // ---------- services, products, value packages ----------
  async recordService(actor: Actor, i: { saleLineId: string; performers: StaffSplit[]; netAmount: string; businessDate: string; foc?: boolean }) {
    this.validateSplits(i.performers, 'Performed by');
    const date = await this.openDate(actor.salonId, i.businessDate);
    const lines = this.makeLines(actor, { splits: i.performers, amount: i.netAmount, type: i.foc ? 'FOC' : 'SVC', businessDate: date, sourceType: 'SALE_LINE', sourceId: i.saleLineId });
    await this.repo.insertLines(lines);
    return { lines };
  }

  async recordProduct(actor: Actor, i: { saleLineId: string; sellers: StaffSplit[]; netAmount: string; businessDate: string; productCategory?: string | null; quantity?: number }) {
    this.validateSplits(i.sellers, 'Sold by');
    const date = await this.openDate(actor.salonId, i.businessDate);
    const lines = this.makeLines(actor, { splits: i.sellers, amount: i.netAmount, type: 'PRD', businessDate: date, sourceType: 'SALE_LINE', sourceId: i.saleLineId, productCategory: i.productCategory, units: i.quantity ?? 1 });
    await this.repo.insertLines(lines);
    return { lines };
  }

  async recordValuePackage(actor: Actor, i: { kind: 'SALE' | 'SPEND'; sourceId: string; staff: StaffSplit[]; businessDate: string; paid: string; credit: string; creditSpent?: string }) {
    this.validateSplits(i.staff, i.kind === 'SALE' ? 'Sold by' : 'Performed by');
    const date = await this.openDate(actor.salonId, i.businessDate);
    const amount = i.kind === 'SALE' ? i.paid : valuePackageSpendBase(i.creditSpent ?? '0', i.paid, i.credit);
    const lines = this.makeLines(actor, { splits: i.staff, amount, type: i.kind === 'SALE' ? 'VP_SALE' : 'VP_SPEND', businessDate: date, sourceType: i.kind === 'SALE' ? 'PAYMENT' : 'SALE_LINE', sourceId: i.sourceId });
    await this.repo.insertLines(lines);
    return { lines };
  }

  async holdingDetail(salonId: string, holdingId: string) {
    const h = await this.repo.getHolding(holdingId);
    if (!h || h.salonId !== salonId) throw notFound('Holding');
    const sessions = await this.repo.listSessionUsage(holdingId);
    const lines = await this.repo.listLines({ salonId, holdingId, includeReversed: true });
    return {
      holding: h,
      redeem: canRedeem(h),
      sessions,
      paymentLines: lines.filter((l) => l.commissionType === 'PKG_SALE'),
      redemptionLines: lines.filter((l) => l.commissionType === 'PKG_RED'),
    };
  }

  private requireManager(actor: Actor) {
    if (actor.role !== 'SUPER_ADMIN' && actor.role !== 'MANAGER') throw forbidden('Manager approval required');
  }
```

```ts
/**

import {
  BaseLine, D, StaffPeriodResult, ZERO, calculateFlatFallback, calculateStaffPeriod, money2,
} from '@glampro/commission-shared';
import type { Adjustment, CommissionPeriod, CommissionRepo } from '../repo/types.js';
import { PlanService } from './planService.js';
import { Actor, badRequest, conflict, forbidden, newId, nowIso, periodRange, prevPeriodKey } from './util.js';

/** Commission types that represent cash collected (used for "collection" and the group metric). */
export const CASH_TYPES = ['SVC', 'PKG_SALE', 'PRD', 'VP_SALE'] as const;

export class PeriodService {
  private plans: PlanService;
  constructor(private repo: CommissionRepo) {
    this.plans = new PlanService(repo);
  }

  async getOrCreate(salonId: string, periodKey: string): Promise<CommissionPeriod> {
    if (!/^\d{4}-\d{2}$/.test(periodKey)) throw badRequest('Period must be YYYY-MM');
    return (await this.repo.getPeriod(salonId, periodKey)) ?? this.repo.savePeriod({ id: newId('per'), salonId, periodKey, status: 'OPEN', calculatedAt: null, approvedBy: null, approvedAt: null });
  }

  /** Salon total cash collected in the period (group metric, FR-INC-04). */
  async groupMetric(salonId: string, periodKey: string): Promise<string> {
    const { from, to } = periodRange(periodKey);
    const lines = await this.repo.listLines({ salonId, from, to, types: [...CASH_TYPES] });
    return money2(lines.reduce((s, l) => s.plus(D(l.baseAmount)), ZERO));
  }

  /** Calculate one staff member for any period (also used for month-to-date estimates). */
  async calculateStaff(salonId: string, staffId: string, periodKey: string, linesOverride?: BaseLine[], group?: string): Promise<StaffPeriodResult> {
    const staff = await this.repo.getStaff(staffId);
    const { from, to } = periodRange(periodKey);
    const lines = linesOverride ?? (await this.repo.listLines({ salonId, staffId, from, to }));
    const settings = await this.repo.getSettings(salonId);
    const a = await this.plans.assignmentAt(staffId, to); // D-5: assignment on last day of the month
    if (!a) return calculateFlatFallback(staffId, periodKey, lines, settings.fallbackRates);
    const v = this.plans.effectiveVersion(await this.repo.listVersions(a.planId), to);
    if (!v) return calculateFlatFallback(staffId, periodKey, lines, settings.fallbackRates);
    const prev = settings.negativeBase === 'CARRY_FORWARD' ? (await this.repo.listResults(salonId, prevPeriodKey(periodKey))).find((r) => r.staffId === staffId) : undefined;
    const carry: Record<string, string> = {};
    prev?.components.forEach((c) => { if (!D(c.carryForwardOut).isZero()) carry[c.componentKey] = c.carryForwardOut; });
    return calculateStaffPeriod({
      staffId, periodKey, joinDate: staff?.joinDate ?? null, planId: a.planId, planVersionId: v.id, definition: v.definition,
      stageEndOverride: staff?.stageEndOverride, lines, carryForward: carry, groupMetric: group ?? (await this.groupMetric(salonId, periodKey)),
      tenureOptions: { joinAfterDayCountsNextMonth: settings.joinAfterDayCountsNextMonth },
    });
  }

  /** FR-CAL-01: run / re-run for an OPEN or CALCULATED period. Manual adjustments are kept. */
  async calculate(actor: Actor, periodKey: string) {
    if (actor.role !== 'SUPER_ADMIN' && actor.role !== 'MANAGER') throw forbidden();
    const p = await this.getOrCreate(actor.salonId, periodKey);
    if (p.status === 'APPROVED') throw conflict('Period is approved and locked');
    const group = await this.groupMetric(actor.salonId, periodKey);
    const staff = (await this.repo.listStaff(actor.salonId)).filter((s) => s.active);
    const results: StaffPeriodResult[] = [];
    for (const s of staff) results.push(await this.calculateStaff(actor.salonId, s.id, periodKey, undefined, group));
    await this.repo.saveResults(actor.salonId, periodKey, results);
    const saved = await this.repo.savePeriod({ ...p, status: 'CALCULATED', calculatedAt: nowIso() });
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'PERIOD_CALCULATE', entity: 'period', entityId: periodKey });
    return { period: saved, groupMetric: group, results };
  }

  async addAdjustment(actor: Actor, a: Omit<Adjustment, 'id' | 'salonId' | 'createdBy' | 'createdAt'>) {
    if (actor.role !== 'SUPER_ADMIN' && actor.role !== 'MANAGER') throw forbidden();
    if (!a.reason?.trim()) throw badRequest('Reason is required');
    const p = await this.getOrCreate(actor.salonId, a.periodKey);
    if (p.status === 'APPROVED') throw conflict('Period is locked – add the adjustment to the next open month');
    return this.repo.saveAdjustment({ ...a, amount: money2(a.amount), id: newId('adj'), salonId: actor.salonId, createdBy: actor.userId, createdAt: nowIso() });
  }

  /** Statement lines for one staff member (FR-PAY-03/04). */
  async statement(salonId: string, periodKey: string, staffId: string) {
    const results = await this.repo.listResults(salonId, periodKey);
    const r = results.find((x) => x.staffId === staffId) ?? (await this.calculateStaff(salonId, staffId, periodKey));
    const staff = await this.repo.getStaff(staffId);
    const { from, to } = periodRange(periodKey);
    const profile = await this.repo.getPayrollProfile(staffId, to);
    const adj = (await this.repo.listAdjustments(salonId, periodKey)).filter((a) => a.staffId === staffId);
    const sumKind = (k: Adjustment['kind']) => adj.filter((a) => a.kind === k).reduce((s, a) => s.plus(D(a.amount)), ZERO);
    const lines = await this.repo.listLines({ salonId, staffId, from, to });
    const collection = lines.filter((l) => (CASH_TYPES as readonly string[]).includes(l.commissionType)).reduce((s, l) => s.plus(D(l.baseAmount)), ZERO);
    const basic = D(profile?.basicSalary ?? '0');
    const fixedOt = D(profile?.fixedOt ?? '0');
    const commission = D(r.commissionTotal).plus(sumKind('COMMISSION_ADJ'));
    const takeHome = basic.plus(fixedOt).minus(sumKind('UNPAID_LEAVE')).plus(commission).plus(D(r.incentiveTotal)).plus(sumKind('OVERTIME')).plus(sumKind('ADDITION')).minus(sumKind('DEDUCTION'));
    const fwl = D(profile?.fwlLevy ?? '0');
    const ratio = collection.gt(0) ? takeHome.plus(fwl).div(collection).mul(100) : null;
    return {
      staff, periodKey, result: r, adjustments: adj,
      payroll: {
        basicSalary: money2(basic), fixedOt: money2(fixedOt), unpaidLeave: money2(sumKind('UNPAID_LEAVE')), commission: money2(commission),
        incentive: r.incentiveTotal, overtime: money2(sumKind('OVERTIME')), additions: money2(sumKind('ADDITION')), deductions: money2(sumKind('DEDUCTION')),
        takeHome: money2(takeHome), fwlLevy: money2(fwl), collection: money2(collection),
        payrollSalesPct: ratio ? ratio.toDecimalPlaces(1).toFixed(1) : null,
        alert: ratio !== null && profile ? ratio.gt(D(profile.payrollSalesAlertPct)) : false,
      },
    };
  }

  async summary(salonId: string, periodKey: string) {
    const p = await this.getOrCreate(salonId, periodKey);
    const staff = await this.repo.listStaff(salonId);
    const rows = [];
    for (const s of staff.filter((x) => x.active)) rows.push(await this.statement(salonId, periodKey, s.id));
    return { period: p, groupMetric: await this.groupMetric(salonId, periodKey), rows };
  }

  /** FR-PAY-01: Super admin approves; lines become PAID and the period is read-only. */
  async approve(actor: Actor, periodKey: string) {
    if (actor.role !== 'SUPER_ADMIN') throw forbidden('Only Super admin can approve');
    const p = await this.getOrCreate(actor.salonId, periodKey);
    if (p.status !== 'CALCULATED') throw conflict('Calculate the period before approving');
    const { from, to } = periodRange(periodKey);
    for (const l of await this.repo.listLines({ salonId: actor.salonId, from, to })) if (l.status === 'EARNED') await this.repo.updateLineStatus(l.id, 'PAID');
    const saved = await this.repo.savePeriod({ ...p, status: 'APPROVED', approvedBy: actor.userId, approvedAt: nowIso() });
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'PERIOD_APPROVE', entity: 'period', entityId: periodKey });
    return saved;
  }

  /** FR-PAY-05: CSV export (opens in Excel). One row per staff × component + payroll lines. */
  async exportCsv(salonId: string, periodKey: string): Promise<string> {
    const s = await this.summary(salonId, periodKey);
    const out: string[][] = [['Period', 'Staff', 'Plan stage', 'Line', 'Base', 'Band', 'Rate %', 'Amount']];
    for (const row of s.rows) {
      const name = row.staff?.name ?? row.result.staffId;
      for (const c of row.result.components) out.push([periodKey, name, row.result.stageName, c.componentName, c.pooledBase, c.bandLabel, c.ratePct ?? '', c.amount]);
      for (const i of row.result.incentives) out.push([periodKey, name, row.result.stageName, `Incentive: ${i.name}`, i.individualMetric, '', '', i.amount]);
      const p = row.payroll;
      for (const [k, v] of Object.entries({ 'Basic salary': p.basicSalary, 'Fixed OT': p.fixedOt, 'Unpaid leave (-)': p.unpaidLeave, Overtime: p.overtime, Additions: p.additions, 'Deductions (-)': p.deductions, 'TOTAL TAKE-HOME': p.takeHome, 'FWL levy (company)': p.fwlLevy, Collection: p.collection, 'Payroll/Sales %': p.payrollSalesPct ?? '' })) out.push([periodKey, name, '', k, '', '', '', v]);
    }
    return out.map((r) => r.map((c) => (/[",\n]/.test(c) ? `"${c.replace(/"/g, '""')}"` : c)).join(',')).join('\n');
  }
}
```

```ts
import {

import type { CommissionRepo } from '../repo/types.js';

export class PlanService {
  constructor(private repo: CommissionRepo) {}

  async list(salonId: string) {
    const plans = await this.repo.listPlans(salonId);
    const staff = await this.repo.listStaff(salonId);
    const today = new Date().toISOString().slice(0, 10);
    const counts: Record<string, number> = {};
    for (const s of staff.filter((x) => x.active)) {
      const a = await this.assignmentAt(s.id, today);
      if (a) counts[a.planId] = (counts[a.planId] ?? 0) + 1;
    }
    return Promise.all(plans.map(async (p) => {
      const versions = await this.repo.listVersions(p.id);
      const current = this.effectiveVersion(versions, today);
      const draft = versions.find((v) => v.status === 'DRAFT') ?? null;
      return { ...p, staffCount: counts[p.id] ?? 0, currentVersion: current, draftVersion: draft, versionCount: versions.length };
    }));
  }

  async get(planId: string) {
    const plan = await this.repo.getPlan(planId);
    if (!plan) throw notFound('Plan');
    const versions = await this.repo.listVersions(planId);
    return { plan, versions };
  }

  async create(actor: Actor, input: { name: string; description?: string; positions: string[]; definition: PlanDefinition; copyFromPlanId?: string }) {
    this.requireAdmin(actor);
    const plan: CommissionPlan = { id: newId('plan'), salonId: actor.salonId, name: input.name, description: input.description, positions: input.positions, status: 'ACTIVE' };
    await this.repo.savePlan(plan);
    let def = input.definition;
    if (input.copyFromPlanId) {
      const src = await this.repo.listVersions(input.copyFromPlanId);
      const cur = this.effectiveVersion(src, new Date().toISOString().slice(0, 10)) ?? src[src.length - 1];
      if (cur) def = cur.definition;
    }
    const v: PlanVersion = { id: newId('pv'), planId: plan.id, versionNo: 1, effectiveFrom: new Date().toISOString().slice(0, 10), reason: 'Created', status: 'DRAFT', definition: def };
    await this.repo.saveVersion(v);
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'PLAN_CREATE', entity: 'plan', entityId: plan.id, after: plan });
    return { plan, draft: v };
  }

  async update(actor: Actor, planId: string, patch: Partial<Pick<CommissionPlan, 'name' | 'description' | 'positions' | 'status'>>) {
    this.requireAdmin(actor);
    const plan = await this.repo.getPlan(planId);
    if (!plan) throw notFound('Plan');
    const next = { ...plan, ...patch };
    await this.repo.savePlan(next);
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'PLAN_UPDATE', entity: 'plan', entityId: planId, before: plan, after: next });
    return next;
  }

  /** Create or replace the single DRAFT version of a plan. */
  async saveDraft(actor: Actor, planId: string, definition: PlanDefinition) {
    this.requireAdmin(actor);
    const versions = await this.repo.listVersions(planId);
    if (!versions.length && !(await this.repo.getPlan(planId))) throw notFound('Plan');
    const existing = versions.find((v) => v.status === 'DRAFT');
    const v: PlanVersion = existing
      ? { ...existing, definition }
      : { id: newId('pv'), planId, versionNo: Math.max(0, ...versions.map((x) => x.versionNo)) + 1, effectiveFrom: new Date().toISOString().slice(0, 10), reason: '', status: 'DRAFT', definition };
    await this.repo.saveVersion(v);
    return { version: v, validation: validatePlan(definition) };
  }

  /** FR-SET-11 / FR-PLN-07 */
  async publish(actor: Actor, versionId: string, effectiveFrom: string, reason: string) {
    if (actor.role !== 'SUPER_ADMIN') throw forbidden('Only Super admin can publish commission plans');
    if (!reason?.trim()) throw badRequest('Change reason is required');
    const v = await this.repo.getVersion(versionId);
    if (!v) throw notFound('Version');
    if (v.status !== 'DRAFT') throw conflict('Only a draft can be published');
    const val = validatePlan(v.definition);
    if (val.errors.length) throw badRequest('Plan has errors', val.errors);
    const period = await this.repo.getPeriod(actor.salonId, periodKeyOf(effectiveFrom));
    if (period?.status === 'APPROVED') throw conflict(`Effective date is inside approved period ${period.periodKey}`);
    const others = (await this.repo.listVersions(v.planId)).filter((x) => x.status === 'PUBLISHED' && x.effectiveFrom === effectiveFrom);
    if (others.length) throw conflict('Another published version already starts on this date');
    const pub: PlanVersion = { ...v, status: 'PUBLISHED', effectiveFrom, reason, publishedBy: actor.userId, publishedAt: nowIso() };
    await this.repo.saveVersion(pub);
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'PLAN_PUBLISH', entity: 'plan_version', entityId: v.id, after: { effectiveFrom, versionNo: v.versionNo }, reason });
    return { version: pub, warnings: val.warnings };
  }

  /** Published version effective on a date (one published version per date – FR-PLN-02). */
  effectiveVersion(versions: PlanVersion[], onDate: string): PlanVersion | null {
    return versions.filter((v) => v.status === 'PUBLISHED' && v.effectiveFrom <= onDate).sort((a, b) => b.effectiveFrom.localeCompare(a.effectiveFrom))[0] ?? null;
  }

  async assignmentAt(staffId: string, onDate: string) {
    const list = await this.repo.listAssignments(staffId);
    return list.filter((a) => a.fromDate <= onDate && (a.toDate === null || a.toDate >= onDate)).sort((a, b) => b.fromDate.localeCompare(a.fromDate))[0] ?? null;
  }

  /** Test calculator + method comparison (FR-SET-07/08). */
  simulate(component: PlanComponent, base: string, stageKey = 'std', units = 0) {
    return { result: calcComponent(component, base, { stageKey, units }), compare: compareMethods(component, base, stageKey) };
  }

  /** Impact preview: last closed month, published vs draft for staff on this plan (FR-SET-10). */
  async impact(actor: Actor, planId: string, draft: PlanDefinition, periodKey: string) {
    const versions = await this.repo.listVersions(planId);
    const { from, to } = periodRange(periodKey);
    const published = this.effectiveVersion(versions, to);
    if (!published) throw badRequest('Plan has no published version for that month');
    const staff = await this.repo.listStaff(actor.salonId);
    const onPlan = [];
    for (const s of staff) {
      const a = await this.assignmentAt(s.id, to);
      if (a?.planId === planId) onPlan.push({ staffId: s.id, staffName: s.name, joinDate: s.joinDate, stageEndOverride: s.stageEndOverride, lines: await this.repo.listLines({ salonId: actor.salonId, staffId: s.id, from, to }) });
    }
    const all = await this.repo.listLines({ salonId: actor.salonId, from, to, types: ['SVC', 'PKG_SALE', 'PRD', 'VP_SALE'] });
    const group = money2(all.reduce((s, l) => s.plus(D(l.baseAmount)), ZERO));
    return impactPreview(periodKey, published.definition, draft, onPlan, group);
  }

  /** Permissions table SRS §4.11: only Super admin creates / edits / publishes plans. */
  private requireAdmin(actor: Actor) {
    if (actor.role !== 'SUPER_ADMIN') throw forbidden('Only Super admin can change commission plans');
  }
}
```

```ts
import { D, money2, resolveStage, stageSchedule, tenureMonth } from '@glampro/commission-shared';

  /** FR-ASN-01/02: assign a plan from a date; closes the previous open assignment. */

    if (!input.reason?.trim()) throw badRequest('Reason is required');
    const s = await this.repo.getStaff(staffId);
    if (!s) throw notFound('Staff');
    if (!(await this.repo.getPlan(input.planId))) throw notFound('Plan');
    if (input.joinDate) await this.repo.saveStaff({ ...s, joinDate: input.joinDate });
    else if (!s.joinDate) throw badRequest('Join date is required');
    const list = await this.repo.listAssignments(staffId);
    for (const a of list) {
      if (a.toDate === null && a.fromDate < input.fromDate) {
        const d = new Date(input.fromDate + 'T00:00:00Z');
        d.setUTCDate(d.getUTCDate() - 1);
        await this.repo.saveAssignment({ ...a, toDate: d.toISOString().slice(0, 10) });
      } else if (a.fromDate >= input.fromDate) {
        throw badRequest('An assignment already starts on or after this date – change that one instead');
      }
    }
    const a = await this.repo.saveAssignment({ id: newId('asg'), staffId, planId: input.planId, fromDate: input.fromDate, toDate: null, reason: input.reason, createdBy: actor.userId, createdAt: nowIso() });
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'PLAN_ASSIGN', entity: 'staff', entityId: staffId, after: a, reason: input.reason });
    return a;
  }

  async setStageOverride(actor: Actor, staffId: string, endMonth: number | null, reason: string) {
    if (actor.role !== 'SUPER_ADMIN' && actor.role !== 'MANAGER') throw forbidden();
    if (!reason?.trim()) throw badRequest('Reason is required');
    const s = await this.repo.getStaff(staffId);
    if (!s) throw notFound('Staff');
    const next: StaffInfo = { ...s, stageEndOverride: endMonth };
    await this.repo.saveStaff(next);
    await this.repo.audit({ salonId: actor.salonId, userId: actor.userId, action: 'STAGE_OVERRIDE', entity: 'staff', entityId: staffId, before: s.stageEndOverride, after: endMonth, reason });
    return next;
  }

  async savePayrollProfile(actor: Actor, p: PayrollProfile) {
    if (actor.role !== 'SUPER_ADMIN') throw forbidden('Only Super admin can change salary data');
    return this.repo.savePayrollProfile({ ...p, basicSalary: money2(p.basicSalary), fixedOt: money2(p.fixedOt), fwlLevy: money2(p.fwlLevy) });
  }

  /** Dashboard header cards + month-to-date per staff (FR-SET-01, FR-RPT-04, C2). */
  async overview(salonId: string, periodKey = periodKeyOf(todayInTz())) {
    const plans = await this.plans.list(salonId);
    const staff = (await this.repo.listStaff(salonId)).filter((s) => s.active);
    const group = await this.periods.groupMetric(salonId, periodKey);
    const rows = [];
    let withoutPlan = 0;
    for (const s of staff) {
      const r = await this.periods.calculateStaff(salonId, s.id, periodKey, undefined, group);
      if (!r.planId) withoutPlan++;
      const tier = r.components.find((c) => c.bandIndex !== null && D(c.pooledBase).gt(0)) ?? r.components.find((c) => c.method.startsWith('TIER_'));
      const plan = plans.find((p) => p.id === r.planId);
      rows.push({
        staffId: s.id, name: s.name, joinDate: s.joinDate, planName: plan?.name ?? 'Flat fallback', stage: r.stageName, tenureMonth: r.tenureMonth,
        mainComponent: tier?.componentName ?? null, mainBase: tier?.pooledBase ?? '0', currentRate: tier?.ratePct ?? null, gapToNext: tier?.gapToNext ?? null,
        estimate: money2(D(r.commissionTotal).plus(D(r.incentiveTotal))),
      });
    }
    return {
      periodKey,
      cards: { activePlans: plans.filter((p) => p.status === 'ACTIVE').length, staffOnPlan: staff.length - withoutPlan, staffWithoutPlan: withoutPlan, drafts: plans.filter((p) => p.draftVersion).length },
      groupMetric: group,
      rows,
    };
  }
}
```

```ts
/** Uses Web Crypto (available in Node 19+ and browsers) so services also run in the frontend mock mode. */
export const newId = (prefix: string) => `${prefix}_${globalThis.crypto.randomUUID().replace(/-/g, '').slice(0, 20)}`;
export const nowIso = () => new Date().toISOString();

/** Today's date (YYYY-MM-DD) in the salon time zone (NFR-02). */
const envTz = (globalThis as { process?: { env?: Record<string, string | undefined> } }).process?.env?.SALON_TZ;
export function todayInTz(tz = envTz || 'Asia/Singapore', d = new Date()): string {
  return new Intl.DateTimeFormat('en-CA', { timeZone: tz, year: 'numeric', month: '2-digit', day: '2-digit' }).format(d);
}

export const periodKeyOf = (date: string) => date.slice(0, 7); // "2026-09-15" -> "2026-09"

export function periodRange(periodKey: string): { from: string; to: string } {
  const [y, m] = periodKey.split('-').map(Number);
  const last = new Date(Date.UTC(y, m, 0)).getUTCDate();
  return { from: `${periodKey}-01`, to: `${periodKey}-${String(last).padStart(2, '0')}` };
}

export function nextPeriodKey(periodKey: string): string {
  const [y, m] = periodKey.split('-').map(Number);
  return m === 12 ? `${y + 1}-01` : `${y}-${String(m + 1).padStart(2, '0')}`;
}
export function prevPeriodKey(periodKey: string): string {
  const [y, m] = periodKey.split('-').map(Number);
  return m === 1 ? `${y - 1}-12` : `${y}-${String(m - 1).padStart(2, '0')}`;
}
```

```tsx
/** Load data with loading / error state; `reload()` to refresh. */
export function useLoad<T>(fn: () => Promise<T>, deps: unknown[]) {
  const [data, setData] = useState<T | null>(null);
  const [error, setError] = useState<unknown>(null);
  const [loading, setLoading] = useState(true);
  const load = useCallback(() => {
    setLoading(true);
    fn().then((d) => { setData(d); setError(null); }).catch(setError).finally(() => setLoading(false));
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, deps);
  useEffect(() => { load(); }, [load]);
  return { data, error, loading, reload: load, setData };
}

/** Run an action with busy + error state. */
export function useAction() {
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<unknown>(null);
  const run = async <T,>(fn: () => Promise<T>): Promise<T | undefined> => {
    setBusy(true); setError(null);
    try { return await fn(); } catch (e) { setError(e); return undefined; } finally { setBusy(false); }
  };
  return { busy, error, run, setError };
}
```

```tsx
function ComponentEditor({ comp, stages, onChange, onRemove }: { comp: PlanComponent; stages: { key: string; name: string }[]; onChange: (c: PlanComponent) => void; onRemove: () => void }) {
  const set = (patch: Partial<PlanComponent>) => onChange({ ...comp, ...patch });
  const setBand = (i: number, patch: Partial<TierBand>) => set({ bands: comp.bands.map((b, j) => (j === i ? { ...b, ...patch } : b)) });
  const toggle = (t: CommissionType) => set({ commissionTypes: comp.commissionTypes.includes(t) ? comp.commissionTypes.filter((x) => x !== t) : [...comp.commissionTypes, t] });
  const setMethod = (m: CalcMethod) => {
    const needsBands = m.startsWith('TIER_') && comp.bands.length === 0;
    set({ method: m, bands: needsBands ? [{ upperLimit: '5000', ratePct: comp.flatRatePct ?? '5', applyMode: 'WHOLE' }, { upperLimit: null, ratePct: '10', applyMode: 'SLICE' }] : comp.bands });
  };
  const addBand = () => {
    const bs = [...comp.bands];
    const last = bs[bs.length - 1];
    if (last && (last.upperLimit === null || last.upperLimit === '')) last.upperLimit = String(Number(bs.length > 1 ? bs[bs.length - 2].upperLimit : 0) + 5000);
    bs.push({ upperLimit: null, ratePct: last?.ratePct ?? '5', applyMode: 'SLICE' });
    set({ bands: bs });
  };
  return (
    <Card title={<>Component: <input value={comp.name} onChange={(e) => set({ name: e.target.value })} style={{ width: 'auto', display: 'inline-block', fontWeight: 700 }} aria-label="Component name" /></>}
      hint="Pick what counts towards this component and how the % is applied."
      actions={<button className="btn ghost sm" onClick={onRemove}>Remove component</button>}>
      <div style={{ fontWeight: 600, color: 'var(--ink)', fontSize: 12, margin: '6px 0' }}>Sales that count (click to toggle)</div>
      <div className="chips">{ALL_TYPES.map((t) => <span key={t} role="button" tabIndex={0} className={`chip ${comp.commissionTypes.includes(t) ? '' : 'off'}`} onClick={() => toggle(t)} onKeyDown={(e) => e.key === 'Enter' && toggle(t)}>{COMMISSION_TYPE_LABELS[t]}</span>)}</div>
      <div className="row">
        <Field label="Base % (e.g. FOC counts 50% of price)"><input className="num" value={comp.basePct} onChange={(e) => set({ basePct: e.target.value })} /></Field>
        <Field label="Monthly cap S$ (blank = none)"><input className="num" value={comp.monthlyCap ?? ''} onChange={(e) => set({ monthlyCap: e.target.value === '' ? null : e.target.value })} /></Field>

      {comp.method === 'FLAT' && <div className="row"><Field label="Rate %"><input className="num" value={comp.flatRatePct ?? ''} onChange={(e) => set({ flatRatePct: e.target.value })} /></Field><div /></div>}

            <tbody>
              {comp.bands.map((b, i) => (
                <tr key={i}>

function CompareTable({ comp, base, stageKey }: { comp: PlanComponent; base: string; stageKey: string }) {
```

## frontend/vite.config.ts

```ts
import react from '@vitejs/plugin-react';
import { fileURLToPath } from 'node:url';
import { defineConfig } from 'vite';

// "@backend" lets the UI's demo/mock mode run the REAL backend services in the browser
// (in-memory repository). In production set VITE_API_URL and the UI calls the REST API instead.
export default defineConfig({
  plugins: [react()],
  resolve: { alias: { '@backend': fileURLToPath(new URL('../backend/src', import.meta.url)) } },
  server: { port: 5173 },
});
```
